## How to use this package

1. **Read the one-page summary first.** It sets the framing and tone for everything else.
2. **Personalise the outreach email.** Replace `[Name]` and the bracketed section with specific details about the advisor and why their particular expertise is relevant.
3. **Attach or link the screenshots** if sending by email, or embed them in a PDF version of the summary.
4. **Do not overclaim.** The package is written to be honest about the early stage of the product. Do not add claims about clinical validation, user numbers, effectiveness, or research backing that are not currently true.

---

## Important — what this package does not claim

- Impulsive is not a medical device.
- It does not diagnose, treat, or cure any mental health condition.
- It does not replace therapy, safeguarding, emergency support, or professional care.
- There is no clinical validation at this stage.
- Advisor outreach is for honest feedback, not endorsement.
